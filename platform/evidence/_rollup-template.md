## Reminders for whatever produces this file

- `total` = sum of the four count columns. `acceptance_rate` = `sent_unedited / total`, or `n/a` if `total < 20` (then `evidence_status = insufficient`).
- Never add a column, a name, an id, an email address, or a content excerpt to this table — if it could identify a person, it does not belong here, full stop.
- A gap in the underlying ledger is recorded in `known_gaps`, not silently absorbed into `window_days`.
