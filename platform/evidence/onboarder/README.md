# Evidence rollups — `onboarder` scope

Generated by the `onboard-evidence-rollup` cron (see `platform/deploy-layer/otpless/scopes/onboarder.md`) per `packs/shared/metrics/SKILL.md`. One immutable file per closed window, named `<window_end>.md`, following the schema in `../README.md`.

Empty until the deployment is live and the agent has produced drafts — there is no evidence yet because the system has not run. An empty directory is the honest state; do not seed it with an example rollup, because a plausible-looking file here could be mistaken for real evidence in a promotion PR.

Counts only. Nothing in this directory may identify a person (ADR-008) — the eval harness enforces that on every file added here.
