# Native SDK Engineer — Android

## Posting

- **Role:** Native SDK Engineer, Android
- **Posting link:** OTPLESS careers page, role #2
- **Comp band:** ₹18–35L mid / ₹35–55L senior / ₹12–18L exceptional junior + ESOPs
- **Owner:** CTO

## Outreach hook patterns

- Reference a specific library/SDK they built or maintain, not an app: "saw you maintain {library} — that's the exact discipline this role needs."
- For OSS maintainers: name their adoption numbers if known.
- For app-only backgrounds with strong fundamentals: "not sure if you'd be open to it, but SDK engineering is a different sport — worth a conversation?"

## Candidate bar

**Hard requirements**
- Has built or maintained a library/SDK other engineers depend on — not only apps.
- Deep Kotlin + Java, battle scars from OEM fragmentation.

**Strong signals**
- Sweats binary size, method count, ProGuard/R8, dependency footprint.
- Low ego, high ownership, taste for small simple APIs.
- Built own product / OSS contributor / identity-auth depth (universal preference, all roles).

**Auto-advance signals**
- Strong Q1 artifact — a real SDK/library with users, not a tutorial project.
- Strong Q4 identity/auth/fraud depth answer.

**Auto-reject signals**
- App-only background, no SDK/library signal anywhere.
- Generic AI-written answers with no specifics about what they built.

## Work-sample brief

Design and partially implement a tiny event-logging SDK: define the public API, versioning strategy, and a size budget; implement enough to demonstrate the API surface and one core logging call. 2–3 hours, AI tools required.

## Role-specific Q&A

| Question | Answer |
|---|---|
| Do you support Java or Kotlin-only consumers? | Both — Kotlin-first API, Java interop maintained. |
| What's the OEM fragmentation story? | You'll own crash-free rate across the OEM zoo — happy to go deep in the work-sample debrief. |

## Evaluation emphasis

API design taste and size/versioning discipline over feature completeness. A small, well-considered public surface beats a large half-finished one.
